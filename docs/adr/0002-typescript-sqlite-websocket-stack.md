# 0002. TypeScript Full-Stack with SQLite and WebSockets

We are building a single-table real-time web application in TypeScript (React/Vite client, Node WebSocket server, and SQLite persistence) rather than a Python backend or Postgres/Next.js cloud stack. Sharing TypeScript across the client and server lets the exact integer Chip, Side Pot, and Settlement engine be verified in one place while keeping deployment as simple as a single Node process with zero external database servers (runnable on a laptop over table Wi-Fi or on a VPS).
