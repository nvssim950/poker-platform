# 0003. Accountless Room Tokens and Host Authority

Players join a Session via an accountless room link or QR code using a display name and a browser-stored reconnect token instead of registered user accounts, while the Host retains sole authority to approve Buy-Ins/Rebuys/Top-Ups/Cash-Outs, resolve Showdowns, step through Undo within the active Hand, and act as a proxy for any Seat. This eliminates signup friction at the table while protecting Cash ledger accuracy and letting the table continue smoothly if a player's phone dies.
